04 불변식 · 정책

  • 🔒 PUBLISHED 이후 회귀 없음 — 발행에 도달하면 발행 이전 상태(DRAFT~SCHEDULED)로 가는 경로가 화이트리스트에 없다. ARCHIVED ⇄ PUBLISHED 만 가능.
  • DRAFT → READY 는 관리자 수동 — 초안 작업 완료는 운영자 책임이라 관리자가 직접 전이시킨다(자동 아님).
  • READY → RECORDING 는 자동 — 콘텐츠 소속 에피소드에 성우가 1명이라도 녹음을 진입하면 자동 전이. 역방향 없음(녹음 시작 이후 READY로 회귀 안 함).
  • RECORDING ⇄ REVIEWING 자동 롤업 — 모든 회차 검수 완료 시 REVIEWING, 회차가 검수에서 회귀하면 다시 RECORDING.
  • REVIEWING ⇄ APPROVED 수동 — 검수자가 완료(APPROVED) / 재검수(REVIEWING).
  • APPROVED ⇄ SCHEDULED — scheduledPublishAt 설정 시 SCHEDULED, 해제 시 APPROVED.
  • SCHEDULED → PUBLISHED 자동 — 예정일 도달 시 스케줄러가 발행(역방향 없음).

05 예정 백엔드

  • scheduledPublishAt (datetime, nullable) 컬럼 — 값이 채워지면 RECORDING/APPROVED → SCHEDULED 자동 전이, 비우면 SCHEDULED → APPROVED.
  • 상태 변경 엔드포인트 — content.transitionTo(next) + canTransitionContent 검증. 예: PUT /admins/contents/:id/status { status }.
  • 스케줄러 — scheduledPublishAt <= now 인 SCHEDULED 콘텐츠를 PUBLISHED 로 전이(주기 잡/예약 잡).
  • 검수 연동 — 회차 단위 EpisodeReview(회차×성우) 완료/회귀가 콘텐츠 RECORDING↔REVIEWING 롤업을 트리거.
관련. 검수 단위·에피소드 상태(DRAFT/READY/RECORDING/REVIEWING/PUBLISHED)는 별도 EpisodeReview 도메인에서 다룬다. 콘텐츠 상태는 그 회차 검수들의 롤업 결과다.
