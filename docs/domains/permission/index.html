Permission · 권한

시스템이 정의한 개별 권한(action)의 카탈로그. 코드(account:read 형태)가 식별자이며, 카테고리로 묶인다. 운영 중 생성/수정되는 데이터가 아니라 시드(seed) 기반 읽기 전용 마스터다.

구현됨 admins/permissions AdminGuard (ADMIN) 읽기 전용

01 책임과 특성

  • 권한의 단일 출처 — 모든 권한 코드는 여기에 등록되며, Role 이 이 코드를 참조해 묶음을 만든다.
  • 코드가 PK — 자동 증가 id 가 아니라 권한 코드 문자열이 기본키. 코드는 action 컨벤션(category:verb)을 따른다.
  • 읽기 전용 표면 — 컨트롤러는 목록 조회만 제공한다. 생성/수정은 시드/마이그레이션으로 관리(런타임 변경 대상 아님).
  • 카테고리 = 화면 그룹 — back-office 권한 UI 의 그룹(계정/역할/권한/콘텐츠/정산/통계/알림/시스템)과 1:1.

04 비즈니스 규칙

  • 변경 불가(런타임) — 생성/수정/삭제 엔드포인트가 없다. 권한 추가는 코드(시드/마이그레이션) 변경으로만.
  • Role 검증의 기준 — Role 생성·수정 시 입력 permissionCodes 가 전부 이 카탈로그에 있어야 통과. 없는 코드는 거부된다.
