Composition · 구성·재생

Cut · 컷

회차(Episode) 본문의 한 컷 = 세로 스크롤 패널 이미지 + 재생 타임라인 컨테이너. 대사(Line)·효과음(SoundEffect)·시각효과(CutEffect)가 이 컷 안의 타임라인에 얹힌다.

설계 admins/episodes/:episodeId/cuts Episode 소속 타임라인 컨테이너
구현 상태 = 설계. Cut은 아직 core-api 모듈로 존재하지 않는다. 타임라인·앵커 모델은 Playback, 부모는 Episode 참고.

01 책임과 특성

  • 세로 스크롤 패널 — 컷은 회차를 구성하는 이미지 한 장. order 순으로 세로로 쌓여 읽힌다.
  • 타임라인 컨테이너 — 컷이 활성(dwell)되는 동안 Line/SoundEffect/CutEffect가 앵커 타임라인 위에서 재생된다(Playback §03).
  • 연출의 단위 — anchorY(정착)·gap(간격)·holdOverride(여운)·imageCropBox(표시영역)가 vooth-tool 연출로 채워진다.
  • 등록 ↔ 연출 분리 — 등록(back-office)은 이미지·순서만, 연출 값은 녹음 이후 vooth-tool에서 채운다(전부 nullable).

02 애그리게이트 — Cut

공통 베이스 DddAggregate(id, createdAt/updatedAt/deletedAt, 이벤트)는 생략.

필수 (등록 = back-office)

03 관계 · 경계

  • ← Episode: episodeId로 소속(논리 FK + INDEX). 부모 Episode.
  • → Line / SoundEffect / CutEffect: 각 요소가 cutId로 Cut을 참조(단방향 — Cut엔 @OneToMany 없음). 앵커 타임라인은 Playback §03·§04.
  • → File: imageFileId로 패널 이미지 참조(key·URL 비저장). 읽을 때 imageUrl 유도(FileService.getPublicUrl).
  • 화면: 등록·이미지·순서는 back-office, 연출(anchorY/gap/hold/cropBox)·미리보기·렌더는 vooth-tool.

04 라이프사이클 · 삭제

  • 생성 — back-office. episode 존재 검증 + order append + 이미지 commit(image/). 연출 값은 null로 시작.
  • 수정 — 이미지/순서(구조) + anchorY/gap/holdOverride/cropBox(연출), 변경 필드만. 상태 게이팅 없음(MVP) — 구조·연출 편집 모두 콘텐츠 상태와 무관. (추후 "구조=DRAFT·READY / 연출=상태무관"으로 분리 검토)
  • 삭제 — 컷 삭제 시 하위 Line/SoundEffect/CutEffect 동반 정리(논리 FK라 앱/이벤트 책임). Line→Recording이 있으면 차단(추후 Recording 도메인).

회차 직속 nested(3단 contents/:c/episodes/:e/cuts는 깊어 회피). 가드: AdminGuard
